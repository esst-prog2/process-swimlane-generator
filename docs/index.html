From Excel to a diagram in three steps

  1. Prepare your workbook. Use the documented Excel template for one complete linear workflow.
  2. Run the Windows command. Install with Python, then run process-map your-workbook.xlsx --viewer.
  3. Open your outputs. Share the SVG or explore the offline HTML with frozen department labels and section bands.
