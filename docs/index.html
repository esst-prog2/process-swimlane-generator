From Excel to a diagram in three steps

  1. Prepare your workbook. Copy the example and enter your tasks, departments and next-step IDs. Use one complete linear workflow.
  2. Run the Windows command. Follow the setup instructions, then run .\.venv\Scripts\process-map.exe your-workbook.xlsx --viewer from the repository folder.
  3. Open your outputs. Share the SVG or explore the offline HTML viewer.
